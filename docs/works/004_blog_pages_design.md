# 004: ブログのページ実装と読みやすさ重視のデザイン

Issue: #4

## 何をしたか

- **記事一覧** `/blog/` + ページネーション(10件/ページ、`/blog/page/2/` 形式。旧Hexoの `per_page: 10` / `pagination_dir: page` を踏襲)
  - 各記事は日付・カテゴリ・タイトル・抜粋(`<!-- more -->` より前のテキスト)を表示
- **タグページ** `/blog/tags/`(タグ一覧・件数付き)+ `/blog/tags/<slug>/`(タグ別一覧)
- **カテゴリページ** `/blog/categories/<slug>/`
- **アーカイブ** `/blog/archives/`(年別グルーピング)
- **RSS** `/blog/atom.xml`(`@astrojs/rss`。旧 hexo-generator-feed のフィードURLを維持)
- **記事ページの強化**
  - 自動目次(h2/h3、2件以上ある記事のみ表示。移行スクリプトで手書きの「## 目次」+ `<!-- toc -->` を除去)
  - 前後記事ナビゲーション、タグ→タグページへのリンク、Blogトップへの戻りリンク
- **リンクカード**: 素URLだけの段落(旧 linkPreview / twitter タグ由来)をドメイン+URL表示のカードに変換する remark プラグインを自作
- **コードブロック**
  - Shiki デュアルテーマ(github-light / github-dark)を導入し、サイトのテーマ切替(OS追従+手動トグル)に連動
  - フェンスの `title="..."` メタをキャプション表示する remark プラグインを自作
- **トップページ**に最新3記事のBlogダイジェストを追加

## 判断

- **Astro 7 の Markdown 処理**: remark プラグインを使うため `@astrojs/markdown-remark` を明示追加(v7からデフォルトプロセッサが変更され、remark利用時は必須)
- リンクカードはビルド時OGP取得をせず、ドメイン+URLのシンプルカードに(外部への依存とビルド時間を避ける。必要になれば後日拡張)
- タグ・カテゴリのURLスラッグは小文字化+スペース/スラッシュをハイフンに変換(旧HexoのタグページURLは維持対象外。Issue #3 の決定を踏襲)

- `pnpm build`: **130ページ**生成、警告なし
- 生成物確認: リンクカード(10件/記事)、コードタイトル、`--shiki-dark` 変数、目次、atom.xml のRSS出力
- Biome チェック通過
