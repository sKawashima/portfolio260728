# 044: Works のタイトルに担当役割を載せる

Issue: #44

## 何をしたか

`src/content/works/*.md`(17件全件)の `title` を「作品名(タグ)は領域、タイトルは何をしたかを表す」形式に変更した。

- `title` を「作品名（役割）」の形式に変更(例: `諦めと戒め` → `諦めと戒め（作曲）`)
- `role` が3つ以上ある場合は、本文・活動内容から意味的に代表的な1〜2件を選んで括弧内に採用(例: `funtousic` の `role: "提案 / Webサイト制作 / イメージ映像 / 映像BGM"` → `funtousic（提案 / Webサイト制作）`)
- `role` に「(一部)」の注記がある項目(例: `hakodate-mirai-project-pre`, `soracamera`, `fusen-no-mori`)は代表役割から除外
- `role` 自体が入れ子の括弧を持つ場合(`hakodate-mirai-project` の `実装（フロント補助 / バック全般）`)は外側の括弧と衝突しないよう `実装` のみに簡略化
- `genres`(一覧・詳細ページのチップ表示)は変更なし。既存のまま「領域」を表す運用を継続
- 詳細ページ(`/works/[id]`)の「担当」欄(`role`)はそのまま残し、タイトルとの重複表示を許容

## 判断

- タイトル形式は「作品名（役割）」「役割：作品名」「役割を副題化」の3案をユーザーに提示し、括弧付加案を採用
- 複数役割は「全部列挙」「代表1〜2件に絞る」で確認し、後者を採用。列挙順が重要度順とは限らないため、機械的な先頭N件ではなく本文の内容を踏まえて代表役割を選定
- `role` フィールド自体の削除・detailsからの除去は行わず、詳細ページは現状維持(ユーザー確認済み)

## 動作確認

- `pnpm build` 成功(132ページ)
- 生成された `dist/works/index.html` で17件すべての `<h3 class="title">` が新しい表記になっていることを確認
- トップページ(`WorksGrid` 経由)・詳細ページとも同じ `work.data` を参照するため表示ロジックの変更は不要
