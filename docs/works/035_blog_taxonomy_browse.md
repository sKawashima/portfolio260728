# 035: ブログのブラウズ性向上(一覧下部へのタグ・カテゴリ一覧)

Issue: #35

## 何をしたか

- `src/lib/blog.ts` に集計ヘルパーを追加: `tagCounts()` / `categoryCounts()`(いずれも件数降順・同数は名前順)
- 新コンポーネント `BlogTaxonomy.astro` を作成。Categories(アウトラインチップ・件数付き → `/blog/categories/:slug/`)と Tags(塗りチップ・件数付き → `/blog/tags/:slug/`)を表示
- ブログ一覧(`/blog/`)とページング(`/blog/page/:n/`)のページネーション下部に、区切り線付きで `BlogTaxonomy` を設置
- `/blog/tags/` の既存のタグ集計ロジックを `tagCounts()` に置き換えて共通化

## 判断

- カテゴリ専用の一覧ページ(`/blog/categories/`)は新設せず、一覧下部のセクションでブラウズ要件を満たした(ページを増やすよりも一覧からの導線の方が自然なため。必要になったら拡張)
- カテゴリとタグはチップの塗り/アウトラインで視覚的に区別した(どちらも案Aのチップ意匠)
- 一覧幅は #34 の決定どおり 720px のまま
