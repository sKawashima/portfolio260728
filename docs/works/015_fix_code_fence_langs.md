# 015: コードフェンスのHexo記法を一括変換

Issue: なし(#3 のフォローアップ、ユーザー依頼)

## 何をしたか

- 移行スクリプト(`scripts/migrate-blog.mjs`)にコードフェンスの変換処理を追加し、全記事を再生成
  - Hexo記法「`言語:タイトル`」→「`言語 title="タイトル"`」(例: ` ```shell:実行コマンド例 ` → ` ```shell title="実行コマンド例" `)
  - ファイル名だけのフェンス(` ```app.js ` 等)は拡張子から言語を推定(例: ` ```js title="app.js" `)
- 対象9記事・85行が変換された

## 結果

- ビルド時の `[Shiki] The language "..." doesn't exist` 警告が**ゼロ**に
- 該当コードブロックのシンタックスハイライトが復活(これまではplaintextフォールバックで無色だった)
- タイトル情報は fence のメタ(`title="..."`)として保持。現状は表示されないが、#4 でキャプション表示に利用する
