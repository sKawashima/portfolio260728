# 002: ポートフォリオの移行と新デザイン実装

Issue: #2

## 何をしたか

- 旧 `portfolio180104` から works コンテンツ(MD 17作品)を移行
  - スキーマは旧 `src/content/config.ts` を踏襲しつつ、Astro 5 の新しいコンテンツコレクションAPI(`glob` loader、`src/content.config.ts`)に更新
  - サムネイル画像12点を `public/` に移設
- トップページを案A(Violet Evolution)デザインで実装
  - ヒーロー: SKロゴ(SVG、アクセント色のストローク)+ 見出し + 単色紫のアクセントライン
  - Works: 薄ラベンダー地(`--color-bg-section`)のセクションに白カードの2カラムグリッド(モバイル1カラム)
  - カード: サムネイル(16:10) / ジャンルチップ / タイトル / 詳細グリッド(活動・人数・担当・期間・時期・技術)/ 概要
  - YouTube作品(4件)は `iframe` 埋め込み(`loading="lazy"`)
  - Footer: 旧タグライン「Art for Design, Design for Development.」を継承、フラットな罫線区切りに変更
- ダークモードは既存トークンで全コンポーネント対応

## 判断

- **ジャンルチップは単一スタイル**(旧実装のジャンル別色分けをやめ、案Aモックアップ通りアクセント基調の統一チップに)。フラットな統一感を優先
- 旧レイアウト(中央罫線+左右交互)は廃止し、カードグリッドに刷新(案A承認済みモックアップ準拠)
- グラデーションはヒーロー・フッター含めすべて不使用(ユーザーフィードバック反映)
- 作品詳細の情報量は旧サイトと同一(削らない)

## 追加対応(ユーザーフィードバック)

- 一覧カードを **サムネ+タイトル+ジャンルチップのみ** に簡素化し、詳細情報(活動・人数・担当・期間・時期・技術・概要)は作品詳細ページ `/works/<slug>/` に移動
- 一覧サムネは **16:9・上端基準トリミング**(`aspect-ratio: 16/9` + `object-fit: cover; object-position: top`)
  - YouTube作品(5件)はYouTube提供の `hqdefault.jpg` を使用。4:3で上下に黒帯があるため中央トリミングに切り替え
- グリッドを3カラム(〜1024px: 2カラム、〜640px: 1カラム)に変更
- 詳細ページ: チップ+タイトル+アクセントライン、YouTube埋め込み or 原寸サムネ、詳細グリッド、概要、外部リンクボタン、Worksへの戻りリンク
- **枠線レス化**: 「線で区切らず余白だけの表現でモダンに」のフィードバックを受け、カードの枠線・背景・Worksセクションの背景・フッターの罫線・詳細ページの情報パネル背景をすべて撤去。余白(グリッドgap 40px等)とサムネの角丸(6px)のみで構成
