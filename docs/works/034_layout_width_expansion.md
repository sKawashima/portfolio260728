# 034: サイト全体のレイアウト幅拡大(コンテナ max-width 1040 → 1400)

Issue: #34

## 何をしたか

- `tokens.css` にレイアウトトークンを追加: `--width-site: 1400px`(ワイド系)/ `--width-prose: 720px`(記事本文)
- ワイド系コンテナ(SiteHeader / トップの hero・digest / Works 一覧 / 404)の 1040px を `var(--width-site)` に置き換え
- ブログ記事本文・一覧系ページは 720px を維持(`--width-prose` にトークン化のみ)
- Works グリッドを固定3カラム → `repeat(auto-fit, minmax(300px, 1fr))` に変更。横幅に応じてカラム数が自動増減(1400px で4カラム、トップのダイジェスト3件は auto-fit なので3カラムに自然に収まる)
- Works 詳細を 800px → 1200px に拡大し、1100px 以上ではメタ情報(dl)を左サイドバー(300px・sticky)、本文を右カラムとする2カラム構成に変更

## 判断

- コンテナ幅 1400px はベストプラクティス(1200〜1440px)のレンジ内。ただし本文テキストは行長45〜75字の可読性セオリーに従い 720px を維持(「広いコンテナ + 狭い prose」構成)
- ブログ一覧系は一度サイト幅(1400px)へ広げたが、プレビュー確認で「見づらい」とのオーナー判断により本文と同じ 720px に戻した(日付+タイトルの行リストは幅を広げても行が間延びするだけのため)
- Works グリッドのカラム数はオーナー要望により固定ではなく幅追従(auto-fit)とした
- ブラウザ拡張未接続のためスクリーンショット確認は未実施。ビルド済み HTML/CSS で全変更の反映を確認
